# 코드에 설명을 적는 규칙

이 저장소의 코드를 읽는 사람은 **이 회사의 일을 모르는 사람**이라고 가정한다.
프로그램을 읽을 줄은 알지만, 왜 이 숫자를 400으로 잡았는지, 왜 '합계'를
왼쪽에서 찾는지는 모른다. 그걸 코드 안에서 알 수 있어야 한다.

## 왜 이렇게 쓰나

한 줄에 여러 단계를 압축해 넣으면 쓰는 사람은 편하지만, 읽는 사람은 그 한
줄을 머릿속에서 다시 풀어야 한다. 혼자 쓸 때는 장점이고 넘길 때는 단점이다.

> 1에서 10까지 더하라고 하면
> 답(55)만 적지 말고, 1+2+3+…+10 이라는 **과정**이 보이게 적는다.

## 규칙 네 가지

### 1. 함수 위에는 '무엇을 · 왜'

```python
def _count_values(ws, sub_row, col):
    """그 열에 실제로 적힌 줄이 몇 줄인가.

    세는 범위는 실제로 읽을 범위와 같아야 한다 — 읽기를 멈추는 자리에서
    세기도 멈춘다. 범위가 어긋나면 엉뚱한 열을 고른다.
    """
```

무엇을 하는지 한 줄, 그 아래에 **왜 이렇게 해야 하는지**. 왜가 없으면
나중에 누군가 "이건 왜 이래?" 하면서 고치고, 고치면 예전 문제가 돌아온다.

### 2. 함수 안은 단계로 끊는다

```python
    # ── 1. 어디부터 어디까지 볼 것인가
    first_row = sub_row + 1
    last_row = min(ws.max_row, sub_row + 400)

    # ── 2. 이 줄의 왼쪽을 통째로 한 문장으로 잇는다
    ...
    # ── 3. 표가 끝나는 줄인가
    ...
```

`# ── 번호. 하는 일` 로 끊는다. 번호가 있어야 "3번에서 걸린다"는 말이
된다. 단계가 둘뿐이면 번호를 안 붙여도 된다.

### 3. 한 줄에 뭉친 것은 풀어 쓴다

압축한 코드:

```python
line = " ".join(_s(ws.cell(r, c).value) for c in range(1, col + 1)).lower()
if any(w in line for w in STOP_WORDS):
    break
```

풀어 쓴 코드:

```python
    # 1열부터 지금 보는 열까지의 칸을 모아 한 줄로 잇는다.
    # '합계'가 이 열이 아니라 왼쪽 1열에 적혀 있을 수 있어서다.
    #   예) 1열 '합계' · 2열 빈칸 · 3열 '120'  →  "합계  120"
    left_cells = []
    for c in range(1, col + 1):
        left_cells.append(_s(ws.cell(r, c).value))
    line = " ".join(left_cells).lower()

    # STOP_WORDS('합계' · '소계' 같은 말)가 하나라도 보이면 표가 끝난 것이다
    hit_stop = False
    for word in STOP_WORDS:
        if word in line:
            hit_stop = True
            break
    if hit_stop:
        break
```

줄 수는 늘지만 읽는 시간이 준다. **이 저장소는 줄 수를 아끼지 않는다.**

### 4. 숫자와 예외에는 이유를 붙인다

코드에 그냥 박힌 숫자(400, 10, 0.7 같은 것)와 `try/except`, `if` 로 빠지는
길에는 **왜 그 값인지 · 어떤 일이 있어서 생겼는지**를 적는다.

```python
    # 400으로 끊는 이유: 시트 아래에 'PPT 붙이는 표'가 붙어 있을 때
    # 끝까지 내려가면 그 표까지 세어 모델이 두 배로 보였다.
    last_row = min(ws.max_row, sub_row + 400)
```

실제로 있었던 사고를 적어 두면, 다음 사람이 같은 자리를 안 밟는다.

## 쓰는 말

- 한국어로 쓴다. 영어 용어는 처음 나올 때 한 번 풀어 준다
- 코드가 **무엇을 하는지**가 아니라 **왜 그렇게 하는지**를 적는다
  (`n += 1  # n을 1 늘린다` 같은 주석은 쓰지 않는다)
- 짧게 쓴다. 한 단계에 두세 줄이면 충분하다
