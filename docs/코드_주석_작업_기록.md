## 세 가지 규칙

| 규칙 | 모양 | 어디에 |
|---|---|---|
| 파일 머리 설명 | `# ====` / `#  제목` / `# ====` (다트 · JS 는 `//`) | 파일 맨 위 |
| 함수 위 설명 | 함수 · 클래스 바로 위 주석 한 줄 이상 (또는 docstring) | 모든 함수 · 클래스 |
| 구분선 | `# ==== 묶음 이름` 또는 `# ---- 묶음 이름` | 함수가 3개 이상인 파일. 한 묶음에 8개를 넘기지 않음 |

구분선으로 인정하는 모양: `=` · `-` 4개 이상, `─` · `━` 6개 이상.

## 주석을 고친 곳 (기존 주석이 틀렸던 것)

- `main.py` — 구역 제목 `수주` → `사장님 지시사항`. 같은 이름 구역이 두 번 나와서 두 번째는 `사장님 지시사항 — 읽기 · 저장 주소` 로 나눔.
- `main.py` — process-leads 설명 한 줄이 엉뚱한 함수 위에 붙어 있어서, 해당 양식 · 적용 설명 쪽으로 옮김.

## 같은 날 함께 바뀐 것 (주석 아님)

- **관리자 쓰기 잠금 풀기** — 엑셀로 들어오는 길이 없는 두 가지는 화면에서 저장되도록 `_ADMIN_OPEN` 으로 옮김:
  - `PUT /admin/home/orders` (사장님 지시사항)
  - `POST /admin/home/division-target`, `POST /admin/revenue/target` (타겟)
  - `POST /admin/revenue/estimate` (예상 · 매입 · 잔특근 직접 입력)는 그대로 잠금.
  - `test_admin_write_lock.py` 를 이에 맞게 고침. 관련 테스트 통과.
